# Моя футбольная карточка

Русскоязычный калькулятор футбольных атрибутов по результатам замеров. Данные сохраняются в браузере. Экспорт профиля в JSON позволяет перенести замеры на другое устройство. В приложении есть вымышленный пример.

## Запуск

Требуется Node.js 24.

```sh
npm install
npm run dev
npm test
npm run build
```

Для GitHub Pages выберите **Settings → Pages → Build and deployment → GitHub Actions**. Пуш в ветку main запускает тесты, сборку и деплой. Vite использует относительный путь к ресурсам.

## Структура

- `src/catalog.ts` — каталог, инструкции, стороны и размеры.
- `src/config.ts` — версия модели, опорные точки, качество и веса.
- `src/model.ts` — валидация, чистые расчёты, сериализация.
- `src/form.tsx`, `src/results.tsx`, `src/main.tsx` — формы, методика, карточка и журнал.

## Формулы

Времена одинаковых попыток сводятся медианой. Для непрерывных значений применяется линейная интерполяция по опорным точкам с ограничением по краям. Для долей используется (успехи + 0,5) / (попытки + 1). Совместимые серии складываются до сглаживания. Ноль попыток оставляет атрибут пустым. Вес сигнала равен весу теста, умноженному на коэффициенты качества и достаточности. OVR и составные баллы рассчитываются по доступным весам при покрытии от 60%. На карточке баллы округляются после вычисления.

Отдельная шкала дистанции даёт предварительный PAC. Для прямого расчёта ускорение весит 45%, спринт — 55%. Карточка вратаря опирается на отдельные атрибуты. Матчевый формат фильтруется в профиле.

## Калибровка

Все стартовые шкалы авторские. Для пересмотра шкалы соберите результаты с одинаковым протоколом и достаточной выборкой. Обновите опорные точки, `basis`, пояснение и версию модели в `src/config.ts`. При смене протокола измените каталог и добавьте отдельную шкалу для нового протокола. Проверьте монотонность, граничные значения и пересчёт ранее сохранённых профилей. Страница методики читает те же значения, что и калькулятор.
